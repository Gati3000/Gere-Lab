Uruchamianie i komendy LabStarting the tool and Lab commandsIniciar la herramienta y comandos Lab

Program uruchamiasz w kontenerze komendą Lab start (lub Lab -up). Panel WWW działa na porcie 8080 i otwiera się od razu na ekranie Home: http://ADRES-KONTENERA:8080.

  • Lab stop (Lab -s) - zatrzymuje program, Lab restart - zatrzymuje i uruchamia od nowa.
  • Lab update - sprawdza gałąź Main i aktualizuje, Lab update -b - to samo dla gałęzi Beta.
  • Lab setup - ponownie uruchamia pierwszą konfigurację, Lab drive - aktualizuje Gere-Drive (jeśli jest zainstalowany).
  • Lab help - pokazuje pomoc.

Retencja i linki działają od razu po zapisaniu. Włączenie Cloud API oraz zmiana hosta lub portu webhooka wymagają Lab restart, bo webhook startuje razem z programem.

Start the program inside the container with Lab start (or Lab -up). The web panel runs on port 8080 and opens straight on the Home screen: http://CONTAINER-ADDRESS:8080.

  • Lab stop (Lab -s) stops the program, Lab restart stops and starts it again.
  • Lab update checks the Main branch and updates, Lab update -b does the same for the Beta branch.
  • Lab setup runs the first-time setup again, Lab drive updates Gere-Drive (if installed).
  • Lab help shows help.

Retention and links take effect as soon as you save. Enabling Cloud API and changing the webhook host or port require Lab restart, because the webhook starts together with the program.

Inicia el programa dentro del contenedor con Lab start (o Lab -up). El panel web funciona en el puerto 8080 y se abre directamente en la pantalla Home: http://DIRECCION-DEL-CONTENEDOR:8080.

  • Lab stop (Lab -s) detiene el programa, Lab restart lo detiene y lo inicia de nuevo.
  • Lab update comprueba la rama Main y actualiza, Lab update -b hace lo mismo con la rama Beta.
  • Lab setup repite la configuración inicial, Lab drive actualiza Gere-Drive (si está instalado).
  • Lab help muestra la ayuda.

La retención y los enlaces surten efecto al guardar. Activar Cloud API y cambiar el host o el puerto del webhook requieren Lab restart, porque el webhook arranca junto con el programa.

Ekran HomeHome screenPantalla Home

Najnowsze wiadomości z WhatsAppLatest WhatsApp messagesÚltimos mensajes de WhatsApp

Lewe okno pokazuje wiadomości odebrane z WhatsAppa: nadawca, data i godzina oraz treść. Lista odświeża się sama co 10 sekund, nic nie trzeba klikać.

Widoczne są tylko wiadomości mieszczące się w ustawionej retencji (patrz grupa Ustawienia). Gdy okno jest puste, wiadomości jeszcze nie przyszły albo żadne źródło WhatsApp nie jest włączone.

The left window shows messages received from WhatsApp: sender, date and time, and the text. The list refreshes by itself every 10 seconds, no clicking needed.

Only messages within the configured retention are shown (see the Settings group). If the window is empty, no messages have arrived yet or no WhatsApp source is enabled.

La ventana izquierda muestra los mensajes recibidos de WhatsApp: remitente, fecha y hora, y el texto. La lista se actualiza sola cada 10 segundos, sin pulsar nada.

Solo se ven los mensajes dentro de la retención configurada (ver el grupo Ajustes). Si la ventana está vacía, aún no ha llegado ningún mensaje o no hay ninguna fuente de WhatsApp activada.

Etykiety do akceptacjiLabels awaiting approvalEtiquetas pendientes de aprobación

Prawe okno zawiera etykiety wysyłkowe przygotowane na podstawie wiadomości: odbiorca, adres, część i przewoźnik. Sprawdzasz dane i wybierasz:

  • Akceptuj - etykieta jest oznaczona jako zaakceptowana.
  • Odrzuć - otwiera okno, w którym opisujesz, co trzeba poprawić (np. zły adres, błędny numer części), i wysyłasz powód.

Wersja Beta: etykiety na Home są na razie przykładowe, a decyzja Akceptuj/Odrzuć jeszcze nie zapisuje się na serwerze (po odświeżeniu strony znika).

The right window holds shipping labels prepared from the messages: recipient, address, part and carrier. Check the data and choose:

  • Accept - the label is marked as accepted.
  • Reject - opens a window where you describe what needs fixing (e.g. wrong address, wrong part number) and send the reason.

Beta version: the labels on Home are sample data for now, and the Accept/Reject decision is not yet saved on the server (it disappears when the page is refreshed).

La ventana derecha contiene las etiquetas de envío preparadas a partir de los mensajes: destinatario, dirección, pieza y transportista. Revisa los datos y elige:

  • Aceptar - la etiqueta se marca como aceptada.
  • Rechazar - abre una ventana donde describes qué hay que corregir (p. ej. dirección errónea, número de pieza incorrecto) y envías el motivo.

Versión Beta: las etiquetas de Home son de ejemplo por ahora, y la decisión Aceptar/Rechazar todavía no se guarda en el servidor (desaparece al recargar la página).

UstawieniaSettingsAjustes

WhatsApp: trzy sposoby połączeniaWhatsApp: three ways to connectWhatsApp: tres formas de conectar

W Ustawieniach są trzy niezależne bloki. Wypełnij i zaznacz „Używaj” tylko przy tym, z którego korzystasz.

  • Cloud API (Meta) - oficjalne API WhatsApp Business. Meta wysyła wiadomości na webhook tego serwera. Pola: Phone Number ID, Verify token, App secret, Access token oraz Host, Port i Ścieżka webhooka (podpowiedzi: 0.0.0.0, 8081, /webhook), czyli adres, pod którym serwer nasłuchuje.
  • Bridge (WhatsApp Web) - zewnętrzny most do zwykłego WhatsAppa, np. WAHA. Podajesz jego Link (URL) (np. http://localhost:3000), Klucz API i Nazwę sesji (domyślnie default).
  • Dostawca zewnętrzny - pośrednik z oficjalnym API, np. Twilio lub 360dialog. Pola: Account SID / ID klienta, Auth token / klucz API i Numer nadawcy.

Pola z hasłami (tokeny, sekrety, klucze) są ukryte jako ********. Jeśli ich nie ruszysz, zostają bez zmian po zapisie. Dane trafiają do pliku User/Web-Config.yml.

Settings has three independent blocks. Fill in and tick “Use” only for the one you actually use.

  • Cloud API (Meta) - the official WhatsApp Business API. Meta sends messages to this server's webhook. Fields: Phone Number ID, Verify token, App secret, Access token, plus Host, Port and Webhook path (hints: 0.0.0.0, 8081, /webhook), i.e. where the server listens.
  • Bridge (WhatsApp Web) - an external bridge to regular WhatsApp, e.g. WAHA. You enter its Link (URL) (e.g. http://localhost:3000), API key and Session name (default default).
  • External provider - an intermediary with the official API, e.g. Twilio or 360dialog. Fields: Account SID / client ID, Auth token / API key and Sender number.

Secret fields (tokens, secrets, keys) are hidden as ********. If you do not touch them they stay unchanged after saving. Data is stored in User/Web-Config.yml.

Ajustes tiene tres bloques independientes. Rellena y marca «Usar» solo en el que utilices.

  • Cloud API (Meta) - la API oficial de WhatsApp Business. Meta envía los mensajes al webhook de este servidor. Campos: Phone Number ID, Verify token, App secret, Access token, además de Host, Puerto y Ruta del webhook (sugerencias: 0.0.0.0, 8081, /webhook), es decir, dónde escucha el servidor.
  • Bridge (WhatsApp Web) - un puente externo al WhatsApp normal, p. ej. WAHA. Indicas su Enlace (URL) (p. ej. http://localhost:3000), Clave API y Nombre de sesión (por defecto default).
  • Proveedor externo - un intermediario con la API oficial, p. ej. Twilio o 360dialog. Campos: Account SID / ID de cliente, Auth token / clave API y Número remitente.

Los campos secretos (tokens, secretos, claves) se ocultan como ********. Si no los tocas, se mantienen sin cambios al guardar. Los datos se guardan en User/Web-Config.yml.

Retencja wiadomościMessage retentionRetención de mensajes

Co to jest: liczba dni, przez które wiadomości są wyświetlane i przechowywane.

Po co: żeby baza wiadomości nie rosła bez końca, a Home pokazywał tylko świeże sprawy.

  • 0 - zawsze, nic nie jest usuwane (wartość domyślna).
  • Liczba większa niż 0 - starsze pliki wiadomości są trwale kasowane z folderu Gere-Drive/Messeges. Dzieje się to przy zapisaniu ustawień.

Przy zmianie na wartość większą niż 0 panel prosi o potwierdzenie, bo usuniętych plików nie da się odzyskać. Wpisuj tylko całe liczby.

Dni liczone są kalendarzowo (czasem kontenera): 1 = tylko dzisiejsze, 7 = dzisiaj i 6 poprzednich dni. Retencja usuwa tylko pliki wiadomości, nie czyści bazy zapytań Database/gere.db. Home pokazuje maksymalnie 200 najnowszych wiadomości.

What it is: the number of days messages are displayed and kept.

Why: so the message store does not grow forever and Home only shows recent matters.

  • 0 - always, nothing is deleted (the default).
  • A number greater than 0 - older message files are permanently deleted from the Gere-Drive/Messeges folder. This happens when you save the settings.

When you change it to a value above 0 the panel asks for confirmation, because deleted files cannot be recovered. Enter whole numbers only.

Days are counted as calendar days (container clock): 1 = today only, 7 = today and the previous 6 days. Retention deletes message files only, it does not clear the inquiries database Database/gere.db. Home shows at most the 200 newest messages.

Qué es: el número de días que los mensajes se muestran y se conservan.

Para qué: para que el almacén de mensajes no crezca sin límite y Home muestre solo lo reciente.

  • 0 - siempre, no se borra nada (valor por defecto).
  • Un número mayor que 0 - los archivos de mensajes más antiguos se borran de forma permanente de la carpeta Gere-Drive/Messeges. Ocurre al guardar los ajustes.

Al cambiar a un valor mayor que 0 el panel pide confirmación, porque los archivos borrados no se pueden recuperar. Escribe solo números enteros.

Los días se cuentan como días naturales (reloj del contenedor): 1 = solo hoy, 7 = hoy y los 6 días anteriores. La retención borra solo los archivos de mensajes, no limpia la base de consultas Database/gere.db. Home muestra como máximo los 200 mensajes más recientes.

Linki stronPage linksEnlaces

Dodawanie i otwieranie linkówAdding and opening linksAñadir y abrir enlaces

Ekran „Linki stron” to Twoja lista często używanych stron (np. panele przewoźników). Przycisk + dodaje nowy link: nazwa i adres są wymagane, opis jest opcjonalny. Przycisk Otwórz otwiera stronę w nowej karcie.

Adres musi zaczynać się od http:// lub https://. Maksymalnie 200 linków.

The “Page links” screen is your list of frequently used sites (e.g. carrier portals). The + button adds a new link: name and address are required, description is optional. Open opens the site in a new tab.

The address must start with http:// or https://. Up to 200 links.

La pantalla «Enlaces» es tu lista de sitios de uso frecuente (p. ej. portales de transportistas). El botón + añade un enlace: nombre y dirección son obligatorios, la descripción es opcional. Abrir abre el sitio en una pestaña nueva.

La dirección debe empezar por http:// o https://. Máximo 200 enlaces.
